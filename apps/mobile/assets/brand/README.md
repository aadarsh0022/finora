# Finora brand assets

These original vectors combine an F ledger mark with a leaf as the upper bar. The
launcher uses Finora's green palette, without text, embedded fonts, stock artwork,
or external image resources. Edit the SVG sources, then regenerate the PNGs:

```powershell
node scripts/generate-brand.mjs
node scripts/generate-brand.mjs --check
```

Run from the repository root after `pnpm install`. The script resolves the existing
lockfile `sharp` 0.35.5 through Next.js and uses fixed PNG options. It does not need
an additional package or a network request. `--check` compares the generated bytes
with the checked-in PNGs, checks dimensions/transparency, and inspects every visible
adaptive-layer pixel against the safe circle.

- `icon.png`: opaque 1024 × 1024 legacy/iOS icon. No baked-in rounded corners.
- `adaptive-foreground.png`: transparent 1024 × 1024 foreground on green background.
- `adaptive-monochrome.png`: transparent 1024 × 1024 white alpha silhouette for
  Android themed icons. Android supplies its own foreground/background tint.
- `splash-light.png` and `splash-dark.png`: transparent 1024 × 1024 marks paired with
  the app's light/dark background in the Expo SplashScreen plugin.
- `store-icon.png`: opaque 512 × 512 rendition, available for later store materials.

Adaptive artwork stays inside the central 66 dp safe circle of Android's 108 dp
layer, including antialiased edges. Launcher masks are applied by the platform.
See [Android adaptive icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)
and [Expo icon/splash configuration](https://docs.expo.dev/develop/user-interface/splash-screen-and-app-icon/).

Native resources must be regenerated with Expo prebuild before rebuilding Android.
Verify both themed launcher icons and light/dark cold launches on real devices.
Expo Go and development builds do not fully reproduce the standalone splash:
[Expo SplashScreen notes](https://docs.expo.dev/versions/latest/sdk/splash-screen/).
No store upload or publication is performed by these scripts.
